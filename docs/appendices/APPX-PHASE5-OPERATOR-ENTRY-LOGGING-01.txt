APPENDIX ID: APPX-PHASE5-OPERATOR-ENTRY-LOGGING-01
TITLE: Phase 5 Operator Entry Logging (Session + Clipboard Staging + Proof)
STATUS: CANONICAL
APPLIES TO: Phase 5 live execution hardening

------------------------------------------------------------
PURPOSE
------------------------------------------------------------
Define the canonical operator procedure for identifying all Phase 5
entries using Wayland-safe clipboard staging and session logging.
Prevents silent truncation and preserves auditability.

------------------------------------------------------------
CANONICAL STAGING PROCEDURE (WAYLAND-SAFE)
------------------------------------------------------------
1) Preview clipboard (read-only):
   wpb | tee -a "$LOG"

2) Stage clipboard to file:
   STAGE="/tmp/allmight_${P5_SESSION}.clip"
   wp > "$STAGE"

3) Record proof:
   echo "[CLIP_STAGE] $STAGE" | tee -a "$LOG"
   echo "[CLIP_HASH] <sha256>" | tee -a "$LOG"
   echo "[CLIP_LINES] <line_count>" | tee -a "$LOG"

------------------------------------------------------------
EXAMPLE STAGED ENTRY (VERBATIM)
------------------------------------------------------------

wpb | tee -a "$LOG"
STAGE="/tmp/allmight_${P5_SESSION}.clip"
wp > "$STAGE"

echo "[CLIP_STAGE] $STAGE" | tee -a "$LOG"
echo "[CLIP_HASH] $(sha256sum "$STAGE" | awk '{print $1}')" | tee -a "$LOG"
echo "[CLIP_LINES] $(wc -l < "$STAGE")" | tee -a "$LOG"

------------------------------------------------------------
FORBIDDEN
------------------------------------------------------------
- Clipboard must never be piped into execution
- wpb is inspection only
- Execution must be file-based
