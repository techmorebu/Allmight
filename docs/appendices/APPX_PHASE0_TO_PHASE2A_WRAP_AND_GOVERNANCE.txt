PHASE 2A — SHARED_INPUTS (REPLAY-RELATIVE) (COMPLETE / FROZEN)
--------------------------------------------------------------
Objective:
- Rebuild Shared_Inputs in Python with semantics aligned to the Phase 0 sheet.

Critical Discovery (Load-bearing):
- Phase 0 spreadsheet calculations are REPLAY-RELATIVE (row-indexed),
  not “latest-only” based on sorted timestamps.
- FILTER() preserves source order; windowing is anchored to the
  evaluation row context (implicit in the sheet).

Decision (Canonical):
- Path A (Recommended): Lock Shared_Inputs as “replay-relative”.

Validation Evidence:
- Computing Shared_Inputs at different asof_index values produces
  expected changes in:
  Last/Prev Close, SwingHigh_20, SwingLow_20, ATR_14, TrendSimple,
  Last_Volume, AvgVol_20.

Bug Notes:
- BUG-004: Sheet window mismatch vs “latest-only” calculations
  Root cause:
  - Python tail()-based windowing diverges from FILTER+SEQUENCE
    replay-relative semantics.
  Resolution:
  - Replay-relative evaluation introduced and treated as canonical.
