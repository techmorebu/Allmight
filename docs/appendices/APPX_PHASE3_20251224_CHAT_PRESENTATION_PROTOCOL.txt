CHAT & PRESENTATION PROTOCOL

Purpose
-------
Defines how instructions MUST be presented in all future chats.

Required Structure (EVERY STEP)
-------------------------------
Each step must explicitly state:
1. What is being done
2. Why it is required
3. How to execute it (exact commands)
4. How to validate success

Rules
-----
- No ambiguous steps
- No silent assumptions
- No partial commands
- All commands must be copy-safe
- All mutations must be explicit

Why
---
Prevents hallucination, execution drift, and undocumented behavior.
