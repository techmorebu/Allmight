APPENDIX ID: APPX-PHASE7-ARMING-TTL-01
TITLE: Phase 7 Arming TTL Enforcement (Policy + ts_unix)
STATUS: CANONICAL
APPLIES TO: Phase 7

Purpose
-------
Time-box arming so "armed once" cannot remain valid indefinitely.

Policy
------
- config/phase6/arming_policy_v0.json: arming_ttl_seconds (default 900)

Enforcement
-----------
- scripts/phase6/arming_guard.py:
  - Uses policy TTL when require_recent_arming() is called with default max_age_seconds.
  - Prefers rec.ts_unix when present; otherwise falls back to file mtime.
  - Fail-closed on missing/invalid policy:
    - E_ARMING_POLICY_INVALID

END
