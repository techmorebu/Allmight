SECTION 1
DRIP VAULT — GUI PANEL SPECIFICATION
============================================================

This section augments APPENDIX A (GUI & CONTROL PANEL).


------------------------------------------------------------
1.1 DRIP VAULT PANEL (READ-ONLY)
------------------------------------------------------------

FUNCTION
--------
Provide visibility into lifestyle cashflow mechanics without allowing
any discretionary or emotional control.

The DRIP Vault panel is strictly non-executable.


DISPLAYS
--------
- DRIP Vault Status: ENABLED / PAUSED
- Current Weekly Gross Income (WGI)
- Active Tier Name
- Tier Payout Amount (weekly)
- Consecutive Weeks at Current Tier
- Weeks Required for Tier Upgrade
- Cash Protection Layer (CPL) Balance
- Cash Minimum Requirement (CMR = 12× Tier)
- CPL Coverage Ratio (CPL / CMR)
- Profit Lock Mechanism (PLM): ELIGIBLE / LOCKED (reason)
- Ops/Gas Safety Check: PASS / BLOCKING
- Next Scheduled Payout Amount
- Last Payout Timestamp


EXPLICITLY NOT SHOWN
-------------------
- No buttons to force payout
- No manual tier selection
- No override of CPL / CMR logic
- No linkage to execution controls


ALLOWED CONTROLS
----------------
- NONE during LIVE mode

(If configuration toggles exist, they are file-based and require
version bump + re-arming.)


------------------------------------------------------------
1.2 GUI INTEGRATION RULES
------------------------------------------------------------

- DRIP Vault panel is informational only
- DRIP status cannot affect execution lanes
- DRIP panel must clearly state when payouts are blocked and why
- DRIP inactivity must be framed as “system protecting itself”
- DRIP Vault must visually appear downstream of all execution lanes
