APPENDIX ID: APPX-PHASE5-LIVE-ENVELOPE-01
TITLE: Phase 5 Live Execution Envelope (Default-Deny Gating Contract)
STATUS: CANONICAL
APPLIES TO: Phase 5 live execution hardening

------------------------------------------------------------
CONTEXT
------------------------------------------------------------
Phase 5 is the first authorized phase for minimal live execution testing.
The dominant risk is accidental arming or implicit live behavior.

------------------------------------------------------------
OBJECTIVE
------------------------------------------------------------
Provide a single, fail-closed gating envelope that must approve any
live execution attempt.

------------------------------------------------------------
DESIGN (FAIL-CLOSED KEYS)
------------------------------------------------------------
Live execution is allowed ONLY when all keys are satisfied:
1) allow_live=true in config/phase5/live_execution_envelope_v0.json
2) adapter_id is present in allowed_adapters
3) ALLMIGHT_LIVE=1 environment flag is set explicitly
4) exact operator acknowledgement phrase is provided
5) kill-switch file config/phase5/KILL_SWITCH does not exist

Any missing or mismatched key results in DENY.

------------------------------------------------------------
IMPLEMENTATION
------------------------------------------------------------
- config/phase5/live_execution_envelope_v0.json (default-deny)
- scripts/phase5/live_envelope.py (enforcement)
- outputs/phase5/live_audit/*.jsonl (audit trail; must never be used as replay input)

------------------------------------------------------------
CONSTRAINTS
------------------------------------------------------------
- Default-deny by default
- Single-adapter by allowlist discipline
- No retries, no recovery, no autonomy, no scaling
- No changes to scoring, regimes, weights, or Phase 4 capital bounds

------------------------------------------------------------
END
