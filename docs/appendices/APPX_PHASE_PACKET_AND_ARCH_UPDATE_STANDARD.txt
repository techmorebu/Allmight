APPX_PHASE_PACKET_AND_ARCH_UPDATE_STANDARD
===============================================

Purpose
-------
Eliminate phase handoff ambiguity by enforcing a single “Phase Packet” artifact
and an architecture delta trail for every phase wrap.

This appendix is MANDATORY for every phase wrap.

Non-negotiable Wrap Outputs (in addition to existing wrap docs)
---------------------------------------------------------------
Every phase wrap MUST produce:

A) Phase Packet
   - Path: docs/phase{N}/PHASE{N}_PACKET.txt
   - Generated by: python tools/make_phase_packet.py --phase {N}
   - This file MUST include:
     1) Authoritative files to read (ordered)
     2) Architecture pointers (current + delta)
     3) Scope and hard invariants
     4) Next phase “Build Plan” (explicit TODOs)
     5) Operator workflow commands
     6) Chat response / interaction protocol pointers

B) Architecture Delta
   - Path: docs/architecture/deltas/PHASE{N}_ARCH_DELTA.md
   - Minimal requirement: list what changed conceptually (not code diffs).
   - MUST include:
     - New modules / responsibilities
     - Any behavior changes (even “pure” helpers)
     - Any new invariants or constraints
     - Any changes in trust boundaries / adapters / allowlists
     - Any changes in test coverage expectations

Recommended (optional but strongly preferred)
---------------------------------------------
C) Living Architecture Update
   - Path: docs/architecture/ARCHITECTURE.md (or equivalent)
   - Either:
     - Update directly as part of wrap, OR
     - Keep architecture doc stable and rely on deltas, then roll-up periodically.

Rapid Scan Integration Requirement
----------------------------------
tools/rapid_scan.py MUST print:
- Latest handoff
- Latest Phase Packet (if present)
- Latest Architecture Delta (if present)
so a new operator can orient in < 2 minutes.

Operator UX & Chat Rules
------------------------
The Phase Packet MUST explicitly reference:
- docs/appendices/APPX_CHAT_RESPONSE_PROTOCOL.txt
- docs/appendices/APPX_PROJECT_RAPID_SCAN_PROTOCOL.txt
and must list the required operator commands for sanity / preflight.

Failure Modes
-------------
If a future operator asks:
- “What should I read first?”
- “What changed architecturally this phase?”
- “What must be built next phase?”
then the packet or delta trail is incomplete.

END
