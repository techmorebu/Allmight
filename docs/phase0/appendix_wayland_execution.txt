PHASE 0 — WAYLAND EXECUTION SAFETY APPENDIX
=================================

Problem:
Wayland clipboard pasting can silently corrupt multi-line shell scripts.

Solution:
All executable content must be passed via wl-paste using a non-interactive,
pipe-safe execution model.

Canonical Pattern:
    wl-paste --no-newline | bash -euo pipefail

Rationale:
- --no-newline prevents phantom line breaks
- -e  : exit on error
- -u  : error on unset variables
- -o pipefail : fail on any pipeline failure

This pattern is REQUIRED for:
- patch application
- file generation
- multi-command execution
- automated test runs

Deviation is not permitted during build or replay phases.
