BUG-001: "argument must be a range"
Symptom:
- Formulas using INDEX(FILTER(...),start) : INDEX(FILTER(...),end)
- Error: argument must be a range

Root cause:
- FILTER() returns an array, not a sheet range. The ":" range operator requires a real range.

Fix pattern (works on mobile + older Sheets):
- Use INDEX(FILTER(...), SEQUENCE(n,1, ROWS(FILTER(...))-(n-1), 1))
- Wrap with IFERROR to return "" if insufficient rows.

Examples:
SwingHigh_20:
=IFERROR(MAX(INDEX(FILTER(HighRange, conds...), SEQUENCE(20,1, ROWS(FILTER(HighRange,conds...))-19, 1))),"")

AvgVol_20:
=IFERROR(AVERAGE(INDEX(FILTER(VolRange,conds...), SEQUENCE(20,1, ROWS(FILTER(VolRange,conds...))-19, 1))),"")
