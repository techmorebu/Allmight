8. TRANSACTION DESIGN — REQUIRED FAIL-CLOSED ORDER
======================================================================

The transaction runner/design must implement this order:

  G0  bash/tool prerequisites

  G1  cd canonical repo and verify branch main

  G2  verify:
        LOCAL_HEAD == pinned baseline
        REMOTE_MAIN == pinned baseline

  G3  capture git status and prove the nine pre-existing dirty paths are exactly
      the allowed unrelated dirty set

  G4  resolve eight target canonical document paths and verify:
        tracked
        current worktree == committed bytes
        full SHA256 == pinned preimage

  G5  verify authority-original manifest:
        expected count
        every source exists
        source SHA/bytes pinned
        every destination unique
        destination absent or exact allowed state

  G6  prove authorized destination set:
        under docs/
        .md/.txt only
        zero executable/source/runtime paths
        zero overlap with unrelated dirty paths

  G7  generate all updated documents and copied authority originals into a
      transaction staging area OUTSIDE the canonical repo worktree

  G8  hash and validate staged generated output

  G9  immediately before canonical write:
        re-check HEAD
        re-check remote
        re-check git status
        re-check eight preimages
        re-check authority sources

  G10 copy exact generated outputs into authorized canonical destinations only

  G11 verify post-write changed/untracked path set equals expected authorized set

  G12 stage exact paths only:
        git add -- <explicit path list>

      FORBIDDEN:
        git add .
        git add -A

  G13 verify git diff --cached --name-only equals exact authorized staged set

  G14 emit/show:
        git diff --cached --stat
        staged path manifest
        staged content hashes

  G15 commit ONCE

  G16 verify commit changed-path set equals authorized set

  G17 push ONCE

  G18 fetch/verify:
        local HEAD == remote main
        committed path set exact
        unrelated dirty paths preserved unchanged

  G19 emit final preservation verification report

Any mismatch before commit:
  STOP with no commit/push.

Any failure after canonical writes but before commit:
  STOP.
  Do not automatically reset unrelated repository state.
  Report exact preservation-owned paths requiring recovery.

Any push failure:
  preserve local commit.
  Do not amend/recommit automatically.
  report local/remote divergence for Boss ruling.
