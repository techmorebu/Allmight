======================================================================
FINAL BLOCKER — PUBLICATION TARGET IDENTITY NOT PROVEN
======================================================================

Current G3 proves:

  HEAD == expected commit
  origin/main == expected commit
  index empty

It does NOT prove:

  current checked-out branch == main
  remote named origin == the intended Allmight repository

This matters because:

  git commit

creates the commit on the current HEAD context, while:

  git push origin main

pushes the local ref named main.

If HEAD is detached at the expected commit, G3 can pass, the documentation commit
can be created on detached HEAD, and `git push origin main` would not push that new
detached commit.

Likewise, the raw-verification URL is hardcoded to:

  techmorebu/Allmight

but the push target is whatever Git currently calls:

  origin

Without proving the remote mapping, the transaction has two independently defined
publication identities.

That is unacceptable for the first public mutation in this arc.

======================================================================
WHY HEAD == origin/main IS NOT ENOUGH
======================================================================

These are commit identities, not ref/topology identities.

The following state can satisfy current v2 G3:

  HEAD = 923dd...
  origin/main = 923dd...
  HEAD detached

Yet a subsequent `git commit` would not update local `main`.

Therefore branch proof is a separate invariant.

Similarly:

  origin/main

names a remote-tracking ref in the local repository. It does not, by itself,
cryptographically or textually prove which repository URL "origin" currently maps to.

Therefore remote URL proof is a separate invariant.
