======================================================================
BLOCKER 1 — INCOMPLETE / FAILED RUN CAN EXIT 0
======================================================================

Current final result logic prints:

  R80_OFFLINE_NONLAUNCHER_MATRIX=INCOMPLETE

when any case is NOT_IMPLEMENTED, any case fails, an audit fails, or the expected
36 PASS condition is not met.

But the script then calls pack, prints STOP, reaches end-of-file, and returns shell
exit status 0.

That is a false-pass process-status seam.

Required correction:

  PASS path:
    R80_OFFLINE_NONLAUNCHER_MATRIX=PASS
    exit 0

  Any non-PASS path:
    R80_OFFLINE_NONLAUNCHER_MATRIX=INCOMPLETE or FAIL
    print deterministic reason/counters
    pack evidence
    exit NONZERO

At the current scaffold stage, with 36 NOT_IMPLEMENTED:
  expected process exit MUST be nonzero.

Suggested distinction:
  INCOMPLETE because fixture coverage is intentionally absent -> dedicated nonzero
  FAIL because an implemented behavioral case/audit failed -> different nonzero

Exact numeric codes are implementation detail; semantics are not.

======================================================================
BLOCKER 2 — TWO SELF-LINEAGE CHECKS ARE VACUOUS
======================================================================

Current self-lineage section contains:

  sl "EXECUTOR_EXCLUDES_SELF_LINEAGE" \
     "$(grep -c 'SELF_EXCLUDE' "$PATH_EXEC")" \
     "$(grep -c 'SELF_EXCLUDE' "$PATH_EXEC")"

Actual and expected are generated from the SAME expression.

It cannot fail.

It also contains:

  sl "RUNNER_EXCLUDES_SELF_FROM_SCAN" "PRESENT" "PRESENT"

This is entirely hard-coded and cannot fail.

Both are BUG-009-class verifier defects.

The later P5 behavioral checks against the runner and ancestor are useful and should
remain, but they do not make the two vacuous assertions acceptable.

Required correction:

  Replace both with independent predicates whose expected value is fixed by
  authority/specification, not derived from the same observation.

Examples of acceptable shape:

  - prove the exact executor self/ancestor exclusion construction expected by the
    reviewed current bytes and compare against a fixed expectation;
  - prove the runner's own helper/scanner processes cannot enter the candidate set
    using an independent behavioral observation;
  - or remove a redundant claim entirely if it adds no independent evidence.

Never use:
  observation == same observation
or:
  literal PRESENT == literal PRESENT

as certification evidence.

BLOCKER 3 — SAFETY SURFACE IS REPORTED, NOT VERIFIED
======================================================================

Current safety section emits:

  REAL_LAUNCHER_CALL_SITES=0
  START_ALL_CALL_SITES=0
  REAL_KILL_CALL_SITES=0
  SP01_CALL_SITES=0
  GIT_MUTATION_CALL_SITES=0

as hard-coded constants.

Those values do not inspect the runner bytes.

As fixture groups are added, the runner will change substantially. A future accidental
launcher, kill, SP01, or git-mutation call could therefore coexist with a printed
zero.

That is another false-assurance seam.

Required correction:

  Derive each safety-surface result mechanically from the runner's actual bytes,
  using R40-style command-position semantics rather than naive textual grep where
  appropriate.

At minimum verify actual executable call positions for:

  start_all / launcher invocation
  real kill / pkill / killall signal primitives in runner-owned code
  SP01 invocation
  git add
  git commit
  git push
  git reset
  git checkout
  git fetch
  git pull

Be explicit about sourced certified helpers:
  if a helper contains a signal primitive but is only callable against bounded
  non-governed fixtures, distinguish CAPABILITY PRESENT from UNAUTHORIZED CALL SITE.

The audit itself must have known-positive controls so a broken regex cannot return
all zeros and pass vacuously.

Required shape:

  SAFETY_AUDIT_KNOWN_POSITIVE=PASS
  REAL_LAUNCHER_CALL_SITES=<measured>
  START_ALL_CALL_SITES=<measured>
  ...
  SAFETY_SURFACE_AUDIT=PASS|FAIL

Any audit failure contributes to nonzero runner exit.
