DEFECT RULING

The discovered command-substitution behavior is a MATERIAL CORRECTNESS DEFECT.

Previous pattern:

  out="$(signal_one ...)"

combined with:

  stop() { ...; exit 2; }

meant that any stop() invoked inside signal_one() terminated only the command-
substitution subshell. The parent shell could then continue teardown.

Therefore the pre-fix executor did NOT satisfy the core fail-closed invariant.

Potentially affected stop paths included, at minimum:

  TD_IDENTITY_MISMATCH
  TD_EPERM
  TD_SIGNALLED_REUSED_PID
  TD_TERM_TIMEOUT
  any other hard STOP reachable inside signal_one()

This is exactly the class of defect the sandbox matrix is intended to expose.

The defect was found before packaging and before live execution.
No live authority was consumed.

FIX DIRECTION — ACCEPTED

The reported repair direction is ACCEPTED:

  - signal_one called directly, not through command substitution
  - result communicated via global SIG_OUTCOME
  - counters maintained in parent-shell state
  - no signal_one call wrapped in $(...)

This preserves stop() as a process-wide fail-closed exit.

However, this repair is not certified merely by grep or bash -n.

GLOBAL SHELL-STATE AUDIT — REQUIRED

The subshell defect may have affected more than stop propagation.

Audit the executor for every function whose side effects are expected to persist
in parent-shell state.

Specifically search for function calls inside:

  $(...)
  backticks
  pipelines
  process substitutions
  subshell groups: ( ... )

For each such call, determine whether it mutates or relies on:

  counters
  arrays
  state-machine variables
  frozen descendant sets
  teardown outcomes
  STOP flags
  control-transition flags
  start-attempt flags

Any required parent-state mutation occurring in a subshell is a defect.

This audit must be reported explicitly as:

  PERSISTENT_STATE_SUBSHELL_AUDIT PASS|FAIL

and include the list of all remaining intentional subshell uses.

Do not blanket-ban command substitution.
Read-only value capture is allowed.
The rule is:

  parent-required state mutation or hard-stop authority
  MUST NOT depend on subshell persistence.
