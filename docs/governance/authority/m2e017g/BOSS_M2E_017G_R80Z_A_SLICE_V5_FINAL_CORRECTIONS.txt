  printf '%s' " $SELFSET " | grep -q " $c " && continue

Under set -u this is another potential unbound-variable abort.

Even if a sourced P1-P5 helper happens to define a variable with that name,
the A fixture must not depend on accidental global leakage from a sourced
certification helper.

allocation.

  complete runner ancestor chain
  PID 1
  PID 0

and retain existing exclusions for:
  historical baseline PIDs
  canonical pidfile members
  real /proc occupancy

  A_SELF_EXCLUDE

Then mechanically prove for every allocated PID:

  PID_NOT_REAL_PROC
  PID_NOT_HISTORICAL_BASELINE
  PID_NOT_CANONICAL_PIDFILE_MEMBER
  PID_NOT_RUNNER
  PID_NOT_RUNNER_ANCESTOR

Do not rely on globals supplied incidentally by sourced verifier files.

======================================================================

  exp_dead_set

and emits both observed/expected sets.

However the normalized strings passed to record() are:

    live=<...> dead=<...> liveset[...] pidmm=<...>

  unified_verif =
    live=<...> dead=<...> liveset[...] pidmm=<...>

  expected =
    live=<...> dead=<...> liveset[...] pidmm=0

There is no:

  deadset[...]

in the PASS comparison.

Therefore the exact dead-role identity requirement is still presentation
evidence, not a certification predicate.

R80Y Blocker 3 required exact live AND dead sets.

REQUIRED CORRECTION

All three normalized forms must contain both:

  liveset[...]
  deadset[...]

Example shape:

  expected =
    live=5 dead=3
    liveset[activator,fetcher,monitor,shadow_engine,volatility]
    deadset[heat,notification_router,watchdog]
    pidmm=0

  executor_actual =
    executor cardinality + executor live-role set
    AND independently derived dead-role set only if explicitly labeled as such

  verifier_actual =
    ROOT_MAP-derived cardinality, live set, dead set, role->PID identity

Important:
Do not pretend the executor directly emitted a dead-role set if it did not.
Preserve provenance.

A clean normalization may use a case verdict predicate rather than forcing
different evidence sources into one identical prose string. The existing
record() equality model must not erase provenance merely to make strings equal.
