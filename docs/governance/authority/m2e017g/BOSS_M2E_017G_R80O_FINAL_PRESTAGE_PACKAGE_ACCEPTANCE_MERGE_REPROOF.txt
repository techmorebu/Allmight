======================================================================
CORRECTION TO R80N SELF-REFERENCE REQUIREMENT
======================================================================

R80N §4 was over-specified.

A file cannot be required to contain its own final SHA while simultaneously using
that SHA as an immutable verification anchor, because inserting the SHA changes the
file bytes and therefore changes the SHA.

The same circularity applies to embedding the final merged checkpoint SHA inside the
checkpoint overlay when the merged artifact includes that overlay.

Therefore the literal R80N requirement that CHECKPOINT_OVERLAY.md itself carry:

  OVERLAY_SHA
  MERGED_DESTINATION_SHA

is WITHDRAWN.

Correct rule:

  self-referential artifact hashes MUST be stored externally to the bytes they
  authenticate.

Accepted external locations include:

  BUILD_AND_CERTIFICATION_LEDGER.md
  package manifest
  preservation-state/evidence record
  Boss verification directive
  commit/push verification evidence

The overlay may carry non-self-referential source anchors and proof states such as:

  BASE_CHECKPOINT_SHA
  BASE_BYTES
  HOST_MERGE_PROOF
  BASE_PREFIX_MATCH
  OVERLAY_SUFFIX_MATCH
  CANONICAL_REPO_CHANGED_BY_MERGE_CONSTRUCTION

The new overlay correctly embeds neither its own SHA nor a merged destination SHA.
