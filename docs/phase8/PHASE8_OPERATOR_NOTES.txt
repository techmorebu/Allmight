PHASE 8 — OPERATOR NOTES
=======================

What Phase 8 is (operationally)
- A safety boundary and adapter plumbing layer, not a trading layer.
- It is correct and expected that Phase 8 cannot fetch live prices or talk to exchanges.

What you can run
- `pytest -q` (Phase 8 contract tests) should pass.
- Phase 8 broker methods:
  - execute_order: always refuses
  - call: gated, but in Phase 8 is stubbed/refusal-oriented
  - get_market_snapshot:
    - dummy: network-gated (default deny)
    - dummy_toxic: returns sanitized toxic fixture (for redaction tests)

What you must NOT do
- Do not add API keys (Phase 8 refuses secrets resolution by design).
- Do not enable network calls in adapters directly.
- Do not introduce websocket clients, background loops, or hidden retries.
- Do not log exceptions or objects before redaction; treat all logs/traces as hostile artifacts.

Audit posture
- Assume logs/traces/receipts are subpoena-safe artifacts.
- Ensure the string 'authorization' and any token-like values never appear in observable outputs.

Repo hygiene reminder
- If Phase 7 artifacts are untracked, Phase 7 is not reproducible from Git history.
  Add them as-is under a separate commit without edits.
