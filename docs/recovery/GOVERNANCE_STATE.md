# ALLMIGHT — GOVERNANCE STATE

## Boss/CPT separation
Boss decides:
- architecture
- doctrine
- classifications
- thresholds
- phase progression
- authorization gates
- deployment/live execution authority

CPT may:
- implement exactly bounded directives
- validate
- generate evidence
- identify discrepancies
- propose alternatives

CPT may not independently change architecture, thresholds, canonical surfaces, safety gates, deployment state, or execution authorization.

## Evidence rules
- enumerate before normalizing
- counterfactual before excluding
- no rejection != positive evidence
- test the property, not the test name
- zero-result probes must prove a known-positive hit
- skipped file != inspection
- component evidence first; aggregates derive
- producer deployed != authority activated
- heartbeat belongs to worker, not wrapper
- observation != authorization

## Git discipline
- explicit-path staging only
- no `git add -A`
- no `git commit -a`
- stop on unexpected baseline disagreement
- runtime slice returns evidence; it does not silently repair
