# CPT ARCHIVE

This directory indexes retired CPT working-context artifacts. Large ZIPs, raw
logs, screenshots, and exported conversations belong in Google Drive, not Git.

Durable storage model:

- GitHub: canonical versioned governance, recovery state, indexes, hashes.
- Google Drive: immutable/bulk evidence bytes.
- CPT/chat context: small, disposable working set reconstructed from Git + Drive.

No CPT artifact is deletable merely because it is superseded. A superseded
artifact may be the only evidence that a defect existed.

Do not prune a source copy until the corresponding archive is independently
verified.
