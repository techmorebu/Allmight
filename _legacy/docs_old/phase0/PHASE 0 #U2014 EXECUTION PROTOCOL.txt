PHASE 0 — EXECUTION PROTOCOL
Wayland Clipboard Execution Standard
===================================


Purpose:
--------
This protocol defines the mandatory execution standard for applying any
clipboard-based commands that mutate project state.


This rule exists to preserve determinism, auditability, and epistemic
integrity across all phases of the Allmight system.


------------------------------------------------------------


MANDATORY EXECUTION COMMAND
---------------------------


All clipboard-executed commands MUST be executed using:


    wl-paste --no-newline | bash -euo pipefail


This applies to:
- Phase builds
- Patch application
- Replay regeneration
- Configuration changes
- Schema migrations
- Component rebuilds
- Test scaffolding
- One-off corrective scripts


------------------------------------------------------------


FLAG ENFORCEMENT RATIONALE
--------------------------


-e  : Abort immediately on any command failure
-u  : Abort on use of undefined variables
-o pipefail : Fail entire pipeline if any segment fails


This ensures:
- No partial state mutation
- No silent truncation
- No undefined-variable drift
- No false-positive “success”


------------------------------------------------------------


EXCEPTIONS
----------


Deviation from this execution method is ONLY permitted when:


1. The command is explicitly read-only
2. The action is exploratory or diagnostic
3. The output does not mutate code, config, or data artifacts


Such deviations MUST be logged as non-authoritative.


------------------------------------------------------------


STATUS
------


This protocol is FROZEN.
Any violation invalidates trust in downstream artifacts.
