PHASE 9 BUILD NOTES
==================
As-of: 2025-12-31 08:37 UTC

Goal (strict)
- Introduce read-only live connectivity scaffolding ONLY (HTTP snapshot reads).
- NO trading/execution, NO signing endpoints, NO websockets, NO daemons, NO retries, NO secret leakage.
- All egress is allowlist-driven and fail-closed.
- Phase 7 remains the sole execution authority.

What shipped
- Architecture-only spec:
  - docs/phase9/PHASE9_ARCHITECTURE_READONLY_LIVE.txt
- Negative-case test plan:
  - docs/phase9/PHASE9_TEST_PLAN_NEGATIVE_CASES.txt
- Network allowlist scaffolding (deny-first):
  - config/phase9/network_allowlist_v0.json
  - allmight/security/network_gate.py:
    - assert_domain_allowed(adapter_id, capability, domain) -> deny if not allowlisted
    - require_allowed(...) -> deny when network disabled
    - http_get_bytes(...) -> public GET (bytes), max size, timeout, no retries, allowlist enforced
- AdapterBroker integration:
  - allmight/adapters/broker.py:
    - supports Phase 9 operation "market_snapshot_live"
    - enforce allowlist token DENY_NOT_ALLOWLISTED_DOMAIN (deny-first)
    - preserves Phase 8 contract tests (legacy helper + dummy_toxic redaction path)
- Minimal public HTTP snapshot adapter:
  - allmight/adapters/http_snapshot.py
    - Coinbase Exchange public REST snapshot (no credentials)
    - schema validation (requires "price")
    - deny on bad JSON / missing fields / oversized responses
- Tests (Phase 9):
  - default-deny contracts
  - broker refusal + redaction invariants
  - allowlist contract
  - http snapshot adapter tests (urlopen monkeypatch; prove no network on deny)

Key invariants preserved
- Network default-deny remains intact.
- Allowlist is explicit: (adapter_id, capability, domain) with no wildcards.
- Fail-closed on any mismatch/timeout/schema error.
- Redaction applied on outward errors/outputs.
- No retries, no background work, no websockets.

Not implemented (by design)
- No authenticated endpoints, no signing, no order placement, no account access.
- No streaming/websocket feeds.
- No daemonized polling.
